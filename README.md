# my-first-website

使用原生 HTML、CSS、JavaScript 构建的中文个人主页，无框架、无构建步骤，也不加载外部字体或图片。

## 网站功能

- 首页标题、个人介绍与三张技能卡片；所有个人内容均为可替换示例，不代表真实经历或技能水平。
- 保留“点我打招呼”按钮：点击后显示“你好，Codex！”，通过实时播报区域兼顾屏幕阅读器。
- 深色 / 浅色模式：首次跟随系统，手动切换后使用 `localStorage` 保存选择；存储不可用时仍可切换。
- 面向 iPhone 等手机的响应式布局，支持安全区域、至少 44px 高的导航交互区域与清晰的键盘焦点。
- 轻量入场动画、卡片悬停与平滑锚点滚动；尊重系统“减少动态效果”设置。
- 无 JavaScript 时仍可阅读内容和使用导航，主题跟随系统；打招呼与手动主题切换需要 JavaScript。

## 本地预览

直接打开 `index.html` 即可浏览。建议使用本地静态服务器测试主题存储：

```sh
python3 -m http.server 8000
```

在浏览器中访问 `http://localhost:8000`。同一 Wi-Fi 下的 iPhone 也可通过电脑的局域网 IP 预览（需网络允许访问该端口）。

## 自定义内容

- `index.html`：替换“你的名字”、个人介绍、技能名称与说明；同步修改页面标题和描述。
- `styles.css`：调整 `:root` 与深色模式中的配色变量，以及布局和动画。
- `script.js`：打招呼交互与主题按钮逻辑。
- 主题偏好保存在浏览器的 `theme` 键中；删除该键可恢复跟随系统。

## 检查建议

执行 `node --check script.js` 和 `git diff --check`；浏览器中检查窄屏布局、打招呼、主题切换及刷新后保留主题、键盘导航与减少动态效果。

项目无需构建。代码审阅后再自行决定提交、合并或发布。
